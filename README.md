# AIライティングツール

Gemini APIを使った個人用のライティング支援ツール集です。Streamlitのマルチページアプリとして、複数のライティング機能を1つにまとめています。

## 機能一覧

- 📝 ブログ記事作成 — テーマ・想定読者・トーン・文字数などからブログ記事の下書き(またはアウトライン)を生成
- 📧 メール返信作成 — 受信メールと伝えたい要点から返信文の下書きを作成
- 📄 文章要約 — 長い文章を箇条書き・一段落・一文などの形式で要約
- ✍️ 文章校正・添削 — 誤字脱字や表現を修正し、主な変更点を提示
- 🔄 トーン・文体変換 — 文章のトーン(ビジネス・カジュアルなど)を変換
- 💡 タイトル・見出し生成 — 記事内容から複数のタイトル案を生成
- 🌐 翻訳 — 指定した言語・トーンで文章を翻訳

## セットアップ

### 1. 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 2. Gemini APIキーの取得

[Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを取得します。

### 3. APIキーの設定

以下のいずれかの方法で設定してください。

- **方法A: `.env`ファイル** — `.env.example` をコピーして `.env` を作成し、`GEMINI_API_KEY` に取得したキーを設定する

  ```bash
  cp .env.example .env
  ```

- **方法B: アプリ画面から入力** — 起動後、サイドバーのAPIキー入力欄に直接貼り付ける(個人利用でその場限りで使いたい場合に便利)

### 4. アプリの起動

```bash
streamlit run Home.py
```

ブラウザで `http://localhost:8501` が開きます。

## 使い方

1. サイドバーでAPIキー・モデル(`gemini-2.5-flash` など)・temperature(生成の創造性)を設定する
2. 左のナビゲーションから使いたいツールを選ぶ
3. 必要な項目を入力し、生成ボタンを押す
4. 生成結果はページ内に表示され、一部のツールではファイルとしてダウンロードもできる

## 技術スタック

- Python
- [Streamlit](https://streamlit.io/) — UI・マルチページ構成
- [google-genai](https://pypi.org/project/google-genai/) — Gemini API SDK

## 注意事項

- 個人用アプリのため、認証機能・データベースは実装していません
- 入力したAPIキーはブラウザには保存されず、Streamlitの `st.session_state`(実行中のみ有効なメモリ)に保持されます。ブラウザタブを閉じたりアプリを再起動すると再入力が必要です
- `.env` ファイルはGit管理対象外(`.gitignore`済み)です。APIキーを誤ってコミットしないよう注意してください
